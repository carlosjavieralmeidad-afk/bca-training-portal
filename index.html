Google Sheets connection

All users, quiz results, and login data sync to your Google Sheet automatically.

How to manage content

All content — modules, questions, videos, and resources — is managed directly in your Google Sheet. No exporting or uploading to GitHub needed for content changes.

Your Google Sheet has these tabs:

Modules tabAdd/edit module titles, descriptions, video IDs, icons
Questions tabAdd/edit all quiz questions
Resources tabAdd/edit PDF and file download links
Users tabAll users (managed from portal)
Quiz ResultsAuto-logged when users complete quizzes

After editing your Google Sheet, click the button below to reload the portal with your latest content.

Column format for each tab

Modules tab columns:

A: Module ID (e.g. digestion, pain, fertility, patient-comm)
B: Title
C: Description
D: Icon (emoji)
E: Icon Background Color (hex, e.g. #f0ece8)
F: YouTube Video ID
G: Passing Score (number, e.g. 80)
H: Practitioner (TRUE/FALSE)
I: Staff (TRUE/FALSE)
J: Intern (TRUE/FALSE)
K: Practitioner Order (number)
L: Staff Order (number)
M: Intern Order (number)
N: Sequential Lock (TRUE/FALSE)

Questions tab columns:

A: Module ID (must match Modules tab)
B: Question text
C: Option A
D: Option B
E: Option C
F: Option D
G: Correct Answer (A, B, C, or D)
H: Feedback / Explanation

Resources tab columns:

A: Module ID (must match Modules tab)
B: Resource Name
C: Resource Type (e.g. PDF, PPTX, Video)
D: Icon (emoji)
E: Download URL
